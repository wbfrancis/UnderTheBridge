# Issue tracker: GitHub

Issues and specs live in GitHub Issues for `wbfrancis/UnderTheBridge`. Use the `gh` CLI for issue operations.

When a skill says “publish to the issue tracker,” create a GitHub issue. When it says “fetch the relevant ticket,” read the full issue and its comments.

Use GitHub’s native issue dependencies for blocking relationships when available. Otherwise, record blockers explicitly in the issue body.

Pull requests are not a request or triage surface for this project.
